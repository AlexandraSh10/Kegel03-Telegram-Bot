# Kegel03 Telegram Bot

Telegram-бот студии «Кегель» в Улан-Удэ. Работает в личных сообщениях и через команды в существующей группе Kegel03.

## Возможности
- /start, /help — приветствие
- /services — информация о занятиях
- /booking — переход на официальную страницу DIKIDI (если задана)
- /cancel — инструкция по отмене через DIKIDI или администратора
- /address — адрес студии
- /contraindications — ограничения
- /admin — связь с администратором

## Развертывание на Render
1. Войдите в Render, подключите GitHub-репозиторий `AlexandraSh10/Kegel03-Telegram-Bot`.
2. Создайте **Background Worker** с Python, используя `render.yaml` (Blueprint), или задайте build `pip install -r requirements.txt`, start `python bot.py`. Фоновый worker может быть платным — проверьте тариф до подтверждения.
3. Добавьте секретные переменные среды:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather; **никогда не размещайте его в GitHub**.
   - `DIKIDI_BOOKING_URL` — проверенная публичная HTTPS-ссылка записи студии.
   - `ADMIN_CONTACT` — HTTPS-ссылка на Telegram администратора.
4. Запустите worker и протестируйте бота в личных сообщениях, затем добавьте в существующую группу Kegel03. В группе доступны команды; чтение обычных сообщений ограничено Telegram privacy mode.

**Статус:** исходный код загружен, бот ещё не развернут и не запущен.

**Ограничение:** интеграции с API DIKIDI пока нет. Бот не создаёт, не подтверждает и не отменяет запись сам. Для этого потребуется официально разрешённый API DIKIDI и его учётные данные. Не сообщайте пользователю, что запись выполнена, без подтверждения DIKIDI.
